    TECNOLOGÍA

    Progressive Web App

    Race 95 incorpora las características fundamentales de una aplicación web progresiva.

    01

    Instalable

    Puede instalarse desde un navegador compatible y ejecutarse como una aplicación independiente.

    02

    Offline

    Utiliza un Service Worker y caché para mantener disponibles los recursos esenciales.

    03

    Responsive

    La interfaz se adapta a computadoras, tabletas y dispositivos móviles.

    04

    LocalStorage

    Las actividades permanecen guardadas localmente aunque se cierre la aplicación.
